# GLOSSARY · 术语表

> **目的**：消除命名冲突。本项目的文档体系中曾出现**三个不同的「三层」**，
> 其中两个名字几乎一样，导致 `docs/00` 与 `docs/14` 各说各话（见 [15-doc-audit.md](15-doc-audit.md) D8）。
>
> **规则**：一个概念只有一个名字；同一段落中不得出现两个不同含义的「三层」。

## 1. 易混淆术语（优先看这张）

| 术语 | 唯一含义 | 出处 | **不要**叫它 |
|---|---|---|---|
| **记忆三层** | `Profile` / `Episode` / `Session`，关注**访问模式不同** | `04` §1 | 三层架构、三层检索 |
| **信息分层** | `系统测量` / `主人记录` / `AI 推测` / `拟人化设定`，关注**可信度归属** | `00` §3.3 | 三层信息分离、三层信息架构 |
| **展示分层** | `娱乐层` / `事实层` / `健康层`，关注**UI 优先级与抢占** | `14` §4 | 三层信息架构、三层信息分离 |

三者维度完全不同：
- 记忆三层 = 数据放在哪、怎么取
- 信息分层 = 这句话有多可信
- 展示分层 = 界面上谁压谁

> 原先「**三层信息分离**」与「**三层信息架构**」仅差两字，是主要的混淆源。已废弃这两个名字。

## 2. 核心名词

| 术语 | 含义 | 出处 |
|---|---|---|
| **情境 context** | 叫声产生的**场景类别**（等食 / 门口 / 疏毛 / 隔离 / 问候 / 其他）。**可被用户确认** | `03` §1 |
| **意图 intent** | 猫的**内心状态或需求**。**不可验证**，系统不预测它 | `03` §1 |
| ~~猫语翻译~~ | 已废弃的说法。系统做的是 context classification | `03` §1 |
| **宠物档案** | 稳定身份事实 + 必须保留特征 | `00` §2 |
| **must_keep_features** | 多图一致出现的外观特征，作为身份硬约束 | `01` §3.6 |
| **外观一致性校验** | 向量相似度的**唯一**合法用途。**不是**个体身份鉴定 | `00` §3.1 |
| **记忆事件 `MemoryEvent`** | 一条长期记忆，带 `subject` / `polarity` / `valid_from` / `valid_to` | `04` §3 |
| **取代链** | 冲突消解方式：保留历史 + `superseded_by`，**不覆盖** | `04` §3.3 |
| **强化 support_count** | 语义重复时计数 +1，**不新增记录** | `04` §3.2 |
| **个体化程度 λ_c** | `n_c/(n_c+κ)`，分层贝叶斯收缩系数，可展示为「对它的了解程度」 | `03` §3.4 |
| **先验依赖 PRIOR** | 前置任务输出**不进入**后置输入数据，但改变其**输入分布** | `01` §6.2 |
| **唯一的写入点** | `memory_writer`。其他节点只产出 `candidate_memories` | `01` §2.2 |
| **快路径 / 慢路径** | 单意图固定链路 / planner 分解链路 | `01` §2.1 |
| **兜底态 AMBIGUOUS** | **不是一个可路由的意图**，而是「置信度不足→澄清」的状态。故无 `IntentPolicy` | `09` §4 |
| **系统测量** | 从音频 / 图像直接计算的客观量。**可复现** —— 重算一次还是它 | `00` §3.3 |
| **主人记录** | 主人在当时**观察到**（情境 / 动作）与**做过**（结果）的。**系统的知识对象** | `00` §3.3 |
| **案例推理 case-based** | 在这只猫**自己**的标注历史上做 k-NN，输出**计数**（「3 次里 2 次」）而非概率 | `03` §3.4 |
| **归属 attribution** | AI 推测的每句必须能指回具体条目。**是安全机制，不是礼貌用语** | `00` §3.3 |
| **红旗规则** | 确定性健康规则，**不学习**，命中即 L3 | `07` §4 |
| **证据模式 `evidence_mode`** | `acoustic_plus_history` / `case_based` / `measured_only` / `text_only`。**后三者均禁止**数值置信度 | `03` §6 |

## 3. 命名规范

| 规则 | 例 |
|---|---|
| 概念名 + 层级名，不用纯数字 | ✅ `记忆三层` ❌ `三层架构` |
| 英文契约类用 `PascalCase`，字段用 `snake_case` | `PriorAdjustment.target_task_id` |
| 文档引用用 `NN-name.md §X` | `01-architecture.md §6.2` |
| 禁止用「三层」「双轨」等**无主语**的说法 | ✅ `健康模块双轨` ❌ `双轨检测` |

## 4. 已废弃术语

| 废弃 | 原因 | 替代 |
|---|---|---|
| 猫语翻译 / 宠物翻译 | 暗示可逆符号映射，科学上不成立 | 行为解释 / 情境分类 |
| 三层信息分离 | 与「三层信息架构」混淆 | 信息分层 |
| 三层信息架构 | 同上 | 展示分层 |
| 三层架构 / 三层检索 | 「三层」歧义 | 记忆三层 |
| 猫咪身份识别 | 通用 embedding 做不到个体再识别 | 外观一致性校验 |
| 健康系统 / 疾病诊断 | 属许可诊疗活动 | 健康监测与分诊 |
| 观察事实（作为单一层名） | 混同了「可复现的系统测量」与「含判断的主人记录」 | 系统测量 / 主人记录 |
